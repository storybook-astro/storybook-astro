# Sandbox — Astro 5

Test project for validating `@storybook-astro/framework` against **Astro 5** (stable). Deployed as the [Astro 5 demo](https://demo-astro5.storybook-astro.org).

## Pinned Versions

- **Astro**: 5.17.2
- **Storybook**: 10.2.7
- **Vite**: 6.x

## Scripts

```bash
yarn workspace @storybook-astro/sandbox-astro5 storybook    # Dev server on port 6007
yarn workspace @storybook-astro/sandbox-astro5 build-storybook
yarn workspace @storybook-astro/sandbox-astro5 test
```
