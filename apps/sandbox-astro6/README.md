# Sandbox — Astro 6 Beta

Test project for validating `@storybook-astro/framework` against **Astro 6** (beta). Also deployed as the [live demo](https://demo.storybook-astro.org).

## Pinned Versions

- **Astro**: 6.0.0-beta.11
- **Storybook**: 10.2.7
- **Vite**: 7.x

## Scripts

```bash
yarn workspace @storybook-astro/sandbox-astro6 storybook    # Dev server on port 6006
yarn workspace @storybook-astro/sandbox-astro6 build-storybook
yarn workspace @storybook-astro/sandbox-astro6 test
```
