# Storybook Astro — Astro 6 Beta Sandbox

This sandbox validates `@storybook-astro/framework` against **Astro 6** (beta). It is also deployed as the [live demo](https://demo.storybook-astro.org).

## Versions

- **Astro**: 6.0.0-beta.11
- **Storybook**: 10.2.7
- **Vite**: 7.x

## Architecture

The project consists of two main packages:

- **@storybook-astro/framework** — Server-side framework integration (Vite plugins, Astro Container, middleware)
- **@storybook-astro/renderer** — Client-side rendering logic (canvas rendering, HMR, style management)

## Supported Frameworks

Astro components plus six UI framework integrations:

- **Alpine.js** — Lightweight, declarative JavaScript framework
- **React** — Component-based UI library
- **Vue** — Progressive JavaScript framework
- **Svelte** — Compiler-based framework
- **Solid** — Fine-grained reactive framework
- **Preact** — Lightweight React alternative

## Component Examples

Browse the sidebar to explore component examples for each framework. Each example includes a Counter component demonstrating how the framework's reactivity system works within an Astro environment.
