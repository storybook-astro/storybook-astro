---
title: Requirements
description: Version requirements for using Storybook Astro.
---

Before installing, ensure your project meets these requirements:

- **Node.js**: 20.16.0+, 22.19.0+, or 24.0.0+ (required for Storybook 10's ESM-only support)
- **Storybook**: 10.0.0+
- **Astro**: 5.5.3+ or 6.0.0-beta
- **Vite**: 6.0.0+ (7.x supported)

You can check your Node.js version with:

```bash
node --version
```

:::note
`npm create storybook@latest` does not yet recognize Astro as a framework. Use the manual setup described in the [Installation](/docs/getting-started/installation/) guide instead.
:::

See the [Astro 6 Compatibility](/docs/how-it-works/astro6-compat/) page for details on running with Astro 6 beta.
