# Integration Example — Astro 7

Integration example for validating `@storybook-astro/framework` against **Astro 7**. Also deployed as the [Astro 7 demo](https://demo-astro7.storybook-astro.org).

## Pinned Versions

- **Astro**: 7.0.0
- **Storybook**: 10.4.6
- **Vite**: 8.x

## Scripts

```bash
yarn workspace @storybook-astro/integration-astro7 dev          # Dev server on port 6008
yarn workspace @storybook-astro/integration-astro7 build
yarn workspace @storybook-astro/integration-astro7 serve
yarn workspace @storybook-astro/integration-astro7 test
```
