# Alpine.js Components

Alpine.js components are **Astro components** (`.astro` files) that use Alpine directives (`x-data`, `x-on`, `x-text`, `x-show`) for client-side interactivity. They render server-side via the Container API and hydrate with the Alpine runtime at load.

## Configuration

Unlike other framework integrations, Alpine stories don't need `parameters.renderer` — they render as standard Astro components. The Alpine integration is configured in `.storybook/main.js` with an entrypoint that initializes Alpine:

```js
alpinejs({ entrypoint: './.storybook/alpine-entrypoint.js' })
```

The entrypoint imports Alpine and starts it:

```js
import Alpine from 'alpinejs';
Alpine.start();
```

## How It Works

1. Props are received server-side via `Astro.props` and used to generate the markup
2. Alpine directives are embedded as HTML attributes during server rendering
3. When the HTML is injected into Storybook's canvas, Alpine picks up the directives and adds interactivity
4. State is managed entirely client-side via `x-data`

## Required Packages

- `@astrojs/alpinejs` — Astro's Alpine integration
- `alpinejs` — Alpine.js runtime
- `@types/alpinejs` — TypeScript types

## Components

- **Counter** — Simple `x-data` / `x-on:click` counter (no props)
- **Accordion** — Collapsible sections with Alpine directives, props passed via Astro.props (`items`, `allowMultiple`)
