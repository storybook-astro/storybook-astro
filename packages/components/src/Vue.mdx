# Vue Components

Vue components rendered **client-side** via `@storybook/vue3`. The renderer delegates to Vue's `renderToCanvas` for full reactivity support.

## Configuration

Stories must set `parameters.renderer: 'vue'` to trigger framework delegation:

```js
export default {
  parameters: { renderer: 'vue' },
  title: 'Vue/MyComponent',
  component: MyComponent,
};
```

The Vue integration is configured in `.storybook/main.js`. No `include` glob is needed — Vue's Vite plugin handles `.vue` files globally:

```js
vue()
```

> **Note**: `@astrojs/vue` is excluded from Vite's dependency optimization because it imports virtual modules (`virtual:@astrojs/vue/app`) that esbuild cannot resolve. The framework handles this automatically via `vitePluginAstroVueFallback`.

## Required Packages

- `@astrojs/vue` — Astro's Vue integration
- `@storybook/vue3` — Storybook Vue 3 renderer
- `@vitejs/plugin-vue` — Vite Vue plugin
- `vue` — Vue runtime

## Components

- **Counter** — Simple `ref` counter (no props)
- **Accordion** — Collapsible sections with Vue reactive state (`items`, `allowMultiple`)
